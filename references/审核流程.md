## 二、完整审核流程（8步，v2.1版本）

### 第0步：读取平台官方规范文档（🔒 最高权威）

**审核前必须执行**：根据目标平台，读取对应官方规范文档。

```
执行步骤：
1. 确认目标平台（如用户未指定，默认全平台）
2. 检查对应平台规范文档是否存在：
   - 小红书 → 读取 `references/平台规范文档/小红书内容规范.md`
   - 其他平台 → 尝试读取对应文档，不存在则使用内置规则
3. 将规范文档内容作为本次审核的判断依据（优先于内置规则）
```

### 第1步：RedFox 官方违禁词检测（🔒 高优先级）

**此步骤通过 RedFox API 调用官方违禁词库，比规则匹配更准确。**

#### 执行方式

根据目标平台，调用对应的 RedFox 违禁词检测脚本（如已安装对应技能）：

```bash
# 小红书违禁词检测（需安装 xiaohongshu-prohibited-word 技能）
python3 ~/.workbuddy/skills/xiaohongshu-prohibited-word/scripts/check_sensitive_words.py --content="待检测文案"

# 公众号违禁词检测（需安装 wechat-prohibited-word 技能）
python3 ~/.workbuddy/skills/wechat-prohibited-word/scripts/check_sensitive_words.py --content="待检测文案"
```

#### 执行规则

1. **如果目标平台包含小红书** → 调用小红书违禁词检测脚本（如已安装）
2. **如果目标平台包含公众号** → 调用公众号违禁词检测脚本（如已安装）
3. **如果目标平台包含抖音/视频号/快手/B站** → 调用公众号检测脚本（规则通用，如已安装）
4. **多平台发布** → 分别调用对应平台脚本，合并结果
5. **文案超3000字** → 脚本会自动提示分批，按分批流程执行
6. **如未安装 RedFox 系列技能** → 跳过本步骤，直接进入第 1.5 步本地违禁词检测（不依赖外部 API）

#### API Key 配置

环境变量 `REDFOX_API_KEY` 配置在 shell 环境中（如 `~/.zshrc` 或系统环境变量），脚本自动读取。

#### 结果整合

RedFox 返回的结果包含：
- 🔍 **违禁词标记**：原文中命中词加粗显示
- 💡 **替换建议**：每个违禁词的上下文替换方案
- ✏️ **优化文案**：替换后的完整文案

将 RedFox 结果作为审核报告的**第一道关卡**，后续步骤在此基础上继续审查。

**如果 RedFox API 不可用**（网络异常/积分不足等），自动降级到下面的规则匹配审核，并在报告中标注「⚠️ RedFox 检测未执行，使用本地规则匹配」。

#### 5.0 核心违规机制理解（🔴 陈晶文档）

**直播违规的4个层次（不同场景下身份不同，尺度不同）**：
- 短视频（尺度最大）→ 直播间（实时播报，监管困难，尺度严格）→ 挂车后（晋升为商家，适用广告法+市场监管规则）→ 投放（平台以此牟利，要求最高）

**直播违规的3类审核方式**：
1. **违禁词对比+抓取**：触发违禁词立刻判违规，需主播形成肌肉记忆
2. **语境识别**：AI分析上下文，即使没有单个违禁词也会判（如财经类反复出现"现金流+回报+本金"→判股票）
3. **人工巡查**：大直播间有巡管，任何规避方式无效

**直播违规审核的12类范围（不只看话术！）**：
直播话术 | 直播画面 | 商品展示 | 账号设置 | 直播贴片 | 直播封面 | 直播标题 | 背景音乐 | 连麦内容 | 评论互动 | 购物车信息 | 主播行为举止

**违规分级（抖音三级，基本适用所有平台）**：
| 等级 | 处罚 | 典型违规 |
|------|------|---------|
| 一级(严重) | 永久封禁账号 | 涉政、涉黄、涉赌、诈骗、传销、未成年人直播 |
| 二级(中等) | 断播+警告，封禁1天到永久 | 低俗、惊悚、赌博展示、伪科学、侮辱诽谤、诱导打赏 |
| 三级(一般) | 断播，封禁1天到一周 | 着装暴露、抽烟喝酒、危险行为、导流至其他平台 |

**违规后正确操作**：
1. 不要轻易申诉（只有1次机会）
2. 弹窗后不要点"无帮助"
3. 发现违规立刻纠正，说"官方大大，连麦的人他不懂""这个不能说哈"
4. 不要短时间内下播重开，全力补救本场人气数据
5. 违规原因未排除前不能复播，否则加重处罚
6. 同类型违规多次叠加会加重（短时不推荐→弹窗→封禁10分钟→1天→3天→7天→30天）

| 触发词/模式 | 风险等级 | 处理建议 |
|-----------|---------|---------|
| 具体金额承诺 | "月入10万""年入百万""日赚500" | 🔴 高 | 删除具体金额，改为模糊表述 |
| 比例承诺 | "提升300%""翻3倍""ROI 500%" | 🔴 高 | 需标注"历史数据，不代表未来" |
| 对比承诺 | "比同行快10倍""远超竞品" | 🟡 中 | 需提供数据来源 |
| 零风险承诺 | "零风险""无风险""稳赚不赔""保本" | 🔴 高 | 删除"零/无风险"表述 |

#### 8.5.4 课程/服务权益虚假

| 触发词/模式 | 风险等级 | 处理建议 |
|-----------|---------|---------|
| "永久更新""终身回看""终身有效""无限次" | 🔴 高 | 改为具体期限（如"2年内更新""3年回看权"） |
| 口播与详情页不一致 | 🟡 中 | 需确保口播承诺与落地页一致 |
| "名额最后X个""仅限今天" | 🟡 中 | 如属实可保留，如虚假则删除 |

### 第8.7步：隐私脱敏检测（🔒 v2.3 新增）

> 扫描内容中是否泄露个人隐私、客户信息、内部数据或敏感凭证。

#### 8.7.1 客户/人名泄露

| 检测项 | 检测规则 | 风险等级 |
|--------|---------|---------|
| 真实客户全名 | 出现非公众人物的真实姓名 | 🔴 高 |
| 客户公司名 | 出现具体客户公司名（非公开案例授权） | 🟡 中 |
| 客户职位+行业组合 | "某互联网公司产品总监张总"等可定位到个人的描述 | 🟡 中 |
| 聊天记录截图 | 包含客户头像、昵称、真实对话内容 | 🔴 高 |

**处理建议**：替换为"某客户A""某互联网公司""某产品经理"

#### 8.7.2 订单/交易信息泄露

| 检测项 | 检测规则 | 风险等级 |
|--------|---------|---------|
| 订单号 | 出现具体订单编号 | 🔴 高 |
| 交易金额+客户名组合 | "张总付了5万"等 | 🔴 高 |
| 合同细节 | 出现合同条款、付款方式等 | 🔴 高 |
| CRM数据 | 出现pipeline阶段、成交概率等内部数据 | 🟡 中 |

#### 8.7.3 API密钥/凭证泄露

| 检测项 | 检测规则 | 风险等级 |
|--------|---------|---------|
| API Key | 匹配 `sk-`、`ak-`、`Bearer ` 前缀 + 长字符串 | 🔴 致命 |
| 密码/Token | 出现 `password=`、`token=`、`secret=` 后跟值 | 🔴 致命 |
| 数据库连接串 | 出现 `postgresql://`、`mongodb://` 等连接串 | 🔴 致命 |
| OAuth凭证 | 出现 `client_id=`、`client_secret=` | 🔴 致命 |
| 环境变量名+值 | 出现 `LOVART_ACCESS_KEY=xxxx` 等 | 🔴 高 |

**处理建议**：立即删除，替换为 `<API_KEY>` 或 `sk-***` 占位符

#### 8.7.4 截图/图片泄露

| 检测项 | 检测规则 | 风险等级 |
|--------|---------|---------|
| 后台系统截图 | 包含飞书多维表格/CRM/后台界面的完整截图 | 🟡 中 |
| 浏览器地址栏 | 截图中可见内部系统URL | 🟡 中 |
| 通知/消息截图 | 包含微信/飞书通知内容 | 🟡 中 |
| 桌面/浏览器标签 | 截图边缘泄露其他敏感信息 | 🟡 低 |

**处理建议**：截图前打码处理，裁剪敏感区域

#### 8.7.5 内部数据泄露

| 检测项 | 检测规则 | 风险等级 |
|--------|---------|---------|
| 收入数据 | 具体营收数字（非公开分享场景） | 🟡 中 |
| 定价策略 | 内部成本、利润率、定价逻辑 | 🟡 中 |
| 团队/人效 | 团队人数+产出+薪资等组合 | 🟡 中 |
| 未发布产品信息 | 未公开的产品功能/计划 | 🔴 高 |

### 第8.8步：AI内容标识合规（🔒 v2.3 新增）

> 2025年9月起，国内要求标注AI生成内容。检查内容是否满足各平台AI标识要求。

#### 8.8.1 各平台AI标识要求

| 平台 | 标识要求 | 未标识后果 |
|------|---------|-----------|
| 抖音 | 🔒 强制标注"AI生成"（2026年3月起） | 限流→下架→封号 |
| 小红书 | 强制勾选「笔记含AI合成内容」 | 首次警告+限流7天→禁言30天→封号 |
| 视频号 | 需标注AI生成 | 限流→下架 |
| 快手 | 鼓励标注 | 暂无强制处罚 |
| B站 | 鼓励标注 | 暂无强制处罚 |
| 公众号 | 需在文末标注AI辅助 | 限流→下架 |

#### 8.8.2 AI内容判定标准

| AI参与程度 | 是否需标注 | 示例 |
|-----------|-----------|------|
| AI完全生成（文/图/视频） | ✅ 必须标注 | GPT写的文章、AI生成的贴图 |
| AI辅助70%+人工30% | ✅ 必须标注 | AI生成初稿+人工微调 |
| AI辅助50%+人工50% | ✅ 必须标注 | AI生成框架+人工填充内容 |
| AI辅助30%+人工70% | ⚠️ 建议标注 | 人工撰写+AI润色/排版 |
| AI辅助<30%（仅工具性使用） | ❌ 不需要 | 人工撰写+AI检查错别字 |

#### 8.8.3 标注方式

| 内容类型 | 标注方式 | 示例 |
|---------|---------|------|
| 短视频 | 平台内置"AI生成"标签 | 抖音发布时勾选 |
| 小红书图文 | 勾选「笔记含AI合成内容」 | 发布时勾选 |
| 公众号文章 | 文末标注"本文由AI辅助创作" | 文末加一行说明 |
| AI生成图片 | 图片角落标注"AI生成" | 贴图右下角水印 |
| 朋友圈 | 无强制要求 | 自愿标注 |
