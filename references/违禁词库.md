## 1.2 加载规则

1. **审核任一平台内容 = 通用违禁词库 + 该平台专属词库**，两份叠加扫描。
2. 检测脚本用法不变：`--platform 抖音` 即加载「通用 + 抖音」；`--platform` 多值逗号分隔加载多平台。
3. 未列入清单的平台（如 OPC Discover、知识星球）仅执行通用词库。
4. 小红书词库内部保留两级：标注「商业笔记专属」的分类仅品牌合作/带货笔记触发，日常分享豁免。

## 1.3 维护规则

1. **新增平台**：在 `references/违禁词库/` 下新建「{平台名}违禁词库.md」，格式沿用 `## N. 分类名` + `**等级**：Px` + `**违禁词**：` bullets + `**修正建议**：`，脚本自动解析，无需改代码。
2. **词库更新**：直接 Edit 对应平台文件，末尾版本记录追加一行。
3. **实战触发即更新**：任一平台判罚违规后，把命中新词补入对应平台词库。
