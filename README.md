## 🚀 使用

把待发布的文案交给 Agent，说「帮我审核这段文案」即可自动触发：

```
帮我审核这段小红书文案，目标平台小红书：
【标题】3个月瘦20斤，亲测有效！
【正文】用了这款产品，一周就见效，全网最低价...
```

输出结构化审核报告：

```
【综合评分】62/100  ⚠️ 需修改
【本地违禁词自动检测】命中 5 个（P0: 3, P1: 2）
  ├─ P0 绝对化用语：「全网最低价」→ 建议改为「限时优惠价」
  ├─ P0 医疗功效词：「瘦20斤」「一周见效」→ 删除或改为使用感受描述
  └─ P1 承诺保证：「亲测有效」→ 建议改为「我的使用感受」
【发布前检查清单】10 项逐条核对
```
